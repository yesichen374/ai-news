01 / 模型与 Agent · Google 官方

Gemini 4 Hydrogen 全面开放，Antigravity 引入多模型调度

Google 在美国时间 11 月 12 日发布 Gemini 4 Hydrogen，并向 Gemini API、AI Studio 等开放；按北京时间属于 11 月 13 日。API 每百万输入 / 输出 Token 为 $1.50 / $7.50；Antigravity 的 Orchestrator 可在 Carbon 与 Hydrogen 间分配任务，建议先用现有代码库对比质量、耗时及总成本，勿直接全量切换。

原始来源：Google 官方发布（美西 11/12）
02 / 全球服务稳定性 · Anthropic 官方

Claude API、Claude Code 与连接器出现跨产品故障

Anthropic 于今日 21:09（北京时间）开始调查 Claude API、Claude Code 等服务降级；22:36 更新称网页和 API 正在恢复，但 Docs/Sheets 等连接器、Managed Agents 仍受影响。生产调用建议监控错误率、启用限次重试和备用模型，不能将“恢复中”视为全部恢复。

原始来源：Claude 官方事故公告（11/13）
03 / 算力与供应链 · Reuters 调查

逾 32 亿美元中国 AI 算力项目依赖受限 NVIDIA 芯片

路透社北京时间 16:31 发布调查，梳理 150 余份资料，发现总额超 230 亿元人民币的项目及配套建设涉及受出口限制的 H100/H200/H800；金额并非全部为芯片采购。对依赖这些 GPU 的建设和交付，应核实合法可获得性、供货证明和国产替代的迁移成本。

媒体调查：Reuters 11/13 独家报道
04 / 监管与安全 · Reuters 法律报道

多家非营利组织起诉五家前沿 AI 企业，寻求暂停新模型开发

Reuters 于北京时间今日 02:23 报道：相关组织在美国加州起诉 OpenAI、Anthropic、Google、Meta 与 SpaceX AI 业务，要求法院限制前沿模型继续开发。这只是诉讼请求，并非法院禁令；工程团队应关注后续裁定，不必据此停止现有 API 集成。

法律报道：Reuters 11/12 18:23 UTC（北京时间 11/13）

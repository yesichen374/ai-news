GPT-6.1 Terra 上线：Sol 一半 API 单价，更适合高频任务

OpenAI 于美西 10 月 26 日发布 GPT-6.1 Terra；Tibo 在北京时间 10 月 27 日 03:24 发出 Day 22 帖文。新模型已可用于 ChatGPT Work、Codex 和 API（模型 ID gpt-6.1-terra），强调屏幕理解、电脑操作与自然写作。

API 单价：输入 $1 / 输出 $5每百万 token；缓存输入 $0.05。标准单价约为 GPT-6.1 Sol 的一半；长上下文请求有额外阶梯价格。
工程建议：先分流，别全量替换 Sol把资料处理、界面操作、常规代码任务做 A/B 对比。OpenAI 仍建议复杂编程优先 Sol / Astra；调用工具应使用 Responses API。

官方自测 Terminal-Bench 4.0 最大推理档得分 50.3%，优于 GPT-5.6 Terra 的 21.5%；该成绩不是用户项目的质量保证。Tibo 称相对 Sol 有约 2 倍使用效率，不能理解为账户额度自动翻倍。

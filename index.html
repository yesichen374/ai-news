OpenAI 上线 ChatGPT Wallet：AI Agent 获得经用户授权的付款能力

OpenAI 于美国时间 11 月 13 日发布、北京时间 11 月 14 日开始对应的新功能，允许 dots Agent 在用户逐笔审阅、经生物识别授权后用令牌化卡信息付款；首批仅面向符合条件的美国成年 Pro 用户，尚非全球开放。

Microsoft 365 全球故障：11 月 14 日确认全面恢复

微软于北京时间今天对应的周六声明，已恢复此前受影响的全部客户与地区；故障波及 Outlook、Teams、Copilot，且连带影响 OpenAI、Anthropic 的 Microsoft 365 连接器。微软把原因归于网络容量升级相关的技术问题，否认网络攻击或 AI Agent 导致。

工程影响：依赖第三方办公连接器的 Agent 流程仍有单点故障风险。建议检查过去两天失败的邮件、日历与自动化任务，补做重试并设计降级通道。

原始来源：Microsoft 365 Status 官方恢复声明CBS / AP，11 月 14 日恢复报道

01 · 全球 AI 算力生态｜路透确认

英伟达创始人黄仁勋卸任 CEO

02 · 模型 API / 数据主权｜官方文档＋当日公告

OpenAI 在印度开放 API 本地推理

OpenAI 今日公布面向合资格客户的印度境内推理，首批支持 GPT-6 Luna 的 Responses 与 Chat Completions API，处理及适用内容存储均可留在印度。工程团队需核对 Zero Data Retention 资格、地区项目、模型与工具限制及区域加价；这不等于所有 OpenAI 服务都在印度境内运行。

来源：OpenAI · API 数据控制文档PTI · 11/12 公告报道

03 · 国际算力供应｜路透独家、非政策落地

中国 AI 企业加紧预订境外 NVIDIA 算力

路透社 11 月 12 日引述知情人士称，部分中国云厂商与模型实验室正在考虑锁定境外 GPU 云资源，以应对美国可能收紧高端芯片远程访问的风险。拟议的 Remote Access Security Act 尚非已实施的新禁令；依赖境外 GPU 的项目应盘点云区域、合同退订条款与替代算力。

来源：Reuters · 11/12 13:31 北京时间

01｜腾讯 Hy4 开放商用入口，明确模型 API 价格

腾讯今天宣布 Hy4 已在腾讯云 TokenHub、CodeBuddy 等产品中可用，并正通过 OpenRouter 等第三方平台开放 API；输入/输出分别约 $0.90/$2.70 每百万 Token，缓存输入约 $0.045。涉及模型替换或国内交付的项目可先做接口兼容、工具调用与质量实测；官方称权重及系统卡将在未来数日发布，不能视作今日已开源权重。

来源：腾讯 11 月 4 日官方新闻稿

02｜Claude Code 修复 Windows PowerShell 安全钩子拦截失效

Anthropic 今天发布 Claude Code v2.1.318，修复 PowerShell 命令含类型转换、param、using 或属性时，Hook 返回退出码 2 却未能阻断执行的问题；同时修复部分会话恢复、认证与 MCP 稳定性缺陷。依赖 Windows Hook 做安全阻断或 CI 自动化的工程，应升级后针对拒绝执行场景回归测试。

来源：Anthropic 官方 Release · 11 月 4 日 00:01 UTC
